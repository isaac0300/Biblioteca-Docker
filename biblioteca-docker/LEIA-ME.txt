Projeto: Sistema de Biblioteca
================================

Este projeto já vem com o CÓDIGO DA APLICAÇÃO pronto:

  frontend/   -> página web (HTML, CSS, JS) que fala com o backend
  backend/    -> API em Node.js/Express que fala com o MySQL
  banco/      -> script init.sql que cria a tabela "livros"

O que NÃO vem pronto (é a sua atividade):

  frontend/Dockerfile   -> você vai criar
  backend/Dockerfile    -> você vai criar
  docker-compose.yml    -> você vai criar

Siga o Manual — Atividade Prática 2 para criar esses três arquivos,
criar o volume, criar a rede e subir a aplicação com Docker Compose.
